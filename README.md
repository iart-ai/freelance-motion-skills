# Motion Design Business Skills

> The motion design business / freelance toolkit for Claude — brief, price, manage revisions, deliver, and document brand motion without the back-office guesswork.

Five Claude Code skills for freelance motion designers and studios running the business side: turning vague client asks into sign-off-ready briefs, building defensible quotes, capping scope creep, exporting to the right platform specs, and authoring brand motion systems.

## Install

```
npx skills add iart-ai/motion-business-skills
```

Works with Claude Code and 40+ agents.

## What's included

| Skill | What it does |
|---|---|
| [creative-brief](./creative-brief) | Turn a fuzzy client ask into a structured, sign-off-ready motion brief plus the exact clarifying questions to send back. |
| [motion-pricing](./motion-pricing) | Pick a pricing model, run the day-rate math, account for cost drivers, and output a clean line-itemed quote. |
| [client-revisions](./client-revisions) | Cap revision rounds, write SOW language, translate vague feedback, and decline out-of-scope work as a change order. |
| [video-delivery-specs](./video-delivery-specs) | Per-platform spec sheets, a cutdown matrix, caption/accessibility notes, and a pre-delivery QC checklist. |
| [brand-motion-guidelines](./brand-motion-guidelines) | Author a brand motion system with easing/timing tokens, a motion library, logo rules, and accessibility standards. |

## When it activates

- You are starting a motion project and need to scope, brief, or quote it.
- A client request is too vague to act on ("make it pop", "we need something cool").
- Feedback is mounting and scope is creeping past the agreed rounds.
- You are exporting finished motion to social, broadcast, OOH, or web.
- A brand or product needs a documented, consistent motion language.

## Example prompts

- "Turn this vague client request into a creative brief I can get sign-off on."
- "Quote a 30-second flat 2D explainer with two revision rounds and paid social usage."
- "The client keeps asking for small tweaks — write me a change-order email."
- "What are the export specs for Instagram Reels, TikTok, and broadcast?"
- "Write brand motion guidelines with named easing and duration tokens."
